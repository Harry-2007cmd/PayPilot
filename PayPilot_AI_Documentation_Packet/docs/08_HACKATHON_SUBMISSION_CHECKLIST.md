# 08 — Hackathon Submission Checklist

Use the official hackathon rules provided by the entrant as the controlling source. Recheck the current Devpost page before submission in case the rules have changed.

## Core eligibility/viability
- [ ] App is newly created or significantly updated during the submission period.
- [ ] PayPal Developer Platform integration uses Sandbox and is central to the project.
- [ ] An AI tool/model/platform is meaningfully integrated.
- [ ] Application runs consistently on the stated platform.
- [ ] Third-party APIs/SDKs are used under their applicable terms.
- [ ] Explain any significant changes made during the hackathon if the project pre-existed.

## Submission materials (based on supplied rules)
- [ ] Detailed English project description.
- [ ] Working demo URL or clear repository setup/run instructions.
- [ ] Public code repository with source, assets, setup instructions, and an open-source license.
- [ ] Demo account/Sandbox instructions where needed; never publish private secrets.
- [ ] Public YouTube demo video under 3 minutes.
- [ ] Video shows the actual application working on its intended platform.
- [ ] Avoid unauthorized third-party trademarks and copyrighted music.
- [ ] Ensure static prototype is not presented as a functioning app.
- [ ] Verify deadline and time zone on the official submission page.

## Demo narrative (target 2:30–2:50)
1. 0:00–0:20 — State the merchant payment-investigation problem.
2. 0:20–0:55 — Complete a real PayPal Sandbox checkout and show the persisted payment.
3. 0:55–1:25 — Open a real or reproducible labelled investigation and show source evidence.
4. 1:25–2:05 — Ask the AI agent to investigate and show tool-backed findings.
5. 2:05–2:35 — Review a proposed action or safe recommendation; demonstrate approval/audit if the test case supports it.
6. 2:35–2:50 — Explain PayPal + AI integration and impact.

## Judging alignment
- Technological implementation: real Sandbox flow, webhook verification, controlled AI tools.
- Design: cohesive and usable investigation experience.
- Potential impact: specific operational pain and clear time-saving outcome.
- Innovation: evidence-backed multi-step investigation and safe action preparation.
- Presentation: concise, reproducible end-to-end demo.

Do not claim sponsor prize eligibility until the sponsor-specific rules and required integration criteria have been verified.
